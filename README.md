# Neek AI

Kindergarten to 2nd grade learning for Neekenson, taught by Tobi the robot.
Built to encourage speaking: every lesson teaches first with "say it with me", then practice is answered out loud.

- Read with Tobi: words light up as he reads aloud; stories continue from the choice he says.
- Talk Time: one word, two words, sentences, and open "Tell me" talking.
- Grammar, Math, Science: K, 1st and 2nd grade lessons, learn then practice.

Open in Chrome, Edge, or Safari (iPad). Single page: `index.html`.
